# ShopSphere 🛒

ShopSphere is a full-stack e-commerce web application built using the MERN stack. It provides a simple and modern shopping experience with user authentication, product management, shopping cart, checkout, and order management.

## ✨ Features

- User Registration and Login
- JWT Authentication
- Product Listing
- Product Details
- Product Search
- Category Filtering
- Price Sorting
- Shopping Cart
- Increase/Decrease Product Quantity
- Checkout
- Order Creation
- My Orders
- Product Add/Edit/Delete
- Order Status Management
- Responsive Design

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- Bootstrap
- Axios
- React Router

### Backend
- Node.js
- Express.js
- REST API
- JWT
- bcryptjs

### Database
- MongoDB
- Mongoose
